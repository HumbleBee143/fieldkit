Privacy Policy — Lost Pantheon Pipeline

Last updated: 5 August 2026

This privacy policy covers the "Lost Pantheon Pipeline" application, a personal-use automation tool that connects to the TikTok Content Posting API.

Single-user application

This app is built and used exclusively by its developer to publish content to one TikTok account (@lost.pantheon) that the developer owns and controls. It is not offered as a public product or service. There is no public sign-up, and no third parties use this application.

Data we collect

We do not collect, store, or process personal data from any third party. There are no public-facing sign-up forms, accounts, or data collection of any kind from members of the public.

TikTok data used

The only TikTok-related data this application handles is the OAuth access token and Open ID issued by TikTok for the single authorized account, used solely to publish video content on that account's behalf via the TikTok Content Posting API. No other TikTok user data is accessed, read, or stored. This data is never shared with or sold to any third party, and is never used for any purpose beyond publishing the account owner's own content.

Data retention & security

Access and refresh tokens are stored on the developer's own private server infrastructure and are not accessible to any third party.
